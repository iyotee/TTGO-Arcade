Bluetooth isn't available here

This page uses Web Bluetooth: Chrome or Edge on Android, Windows, macOS, Linux or ChromeOS. iPhone and iPad browsers (Safari, and Chrome on iOS) and Firefox don't support it. The page must be opened over HTTPS (e.g. GitHub Pages) or from localhost. On iPhone you can still use the board's Remote app: Settings > Bluetooth > TTGO-Arcade.

WiFi for the board

No typing on the board. The first time, your phone asks to pair with TTGO-Arcade: the password only travels over the encrypted link and is not stored by this page. Open networks: leave the password empty.

Clock

Sets the board's clock without WiFi. The Clock app shows it in its own time zone.

Install games

Looking for games...

The big games live in a separate "cartridge" next to the board's own firmware. Keep the board's Companion app open, on USB or with some battery left, and this page in front (the screen stays on). Your phone may ask to pair: accept. If the link drops, tap Install again: it carries on where it stopped. Installing a launcher update later erases the cartridge; the board offers to download it again.
